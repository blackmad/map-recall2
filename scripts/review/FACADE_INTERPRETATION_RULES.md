# Source interpretation and visual review rules

## Upper-floor window-doors

User correction, 20 September 2026: case 30, Rozengracht 212.
An upper-floor door between aligned windows, especially opening onto a balcony,
is often a glazed balcony/French door. Do not render it as a solid paneled
ground-floor entrance merely because the detector classified it as `door`.

Keep function and appearance separate: a door can have window-like glazing,
transoms, mullions and frames. Use floor position, neighboring window rhythm
and a visible balcony as cues to inspect the photograph. Record the observed
glazing, opaque lower panels, leaf count and frame style explicitly; preserve
`kind: door` where appropriate and use the supported glazed-door treatment.
Do not blindly convert every door between windows to glass, or convert curtain
edges into structural bars. If the appearance is hidden, keep it uncertain
instead of presenting a solid entrance-door default as observed evidence.

Self-review must compare the glass-to-panel proportions and frame rhythm of
each upper-floor door against adjacent windows. A generic brown solid door in
a balcony/window row is a mandatory review flag. Ground-floor entrance styling
must be preserved unless its own source evidence supports a correction.

Apply corrections through source-bound data and the shared compiler, retaining
prior candidates and feedback. Verify both the source study and the actual-owner
preview so improved appearance survives runtime delivery and regeneration.
