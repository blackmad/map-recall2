# Ten ordinary building game review

Game integration harness: `scripts/review/check-ordinary-ten-game.mjs`, run serially for `desktop` and `touch` against the working application at `http://localhost:4403/canal-drive/`. Captures and raw measurements live in this directory. This is actual running gameplay, retaining the normal map/camera sync and the stationary rider; the review detaches the camera to each geographically correct native model site, then performs an input drag on desktop/touch and captures a wider camera.

The catalogue contains exactly ten models. Ordinary specifications provide native surveyed polygons for selection, exact BAG IDs for replacement suppression, and `spatialSuppression: false`. They have no curated landmark identity and do not add route POIs. The shared lazy signature loader holds generic geometry until successful decode, invokes the vector map's full synchronization on load, and uses the same loaded model visibility for the Three shader and independent pyramidal-roof mask.

Runtime checks will require every model to load, exact target suppression in the Three shader and pyramid hidden-ID set, zero broad footprint suppression, zero invented route POIs, and a stationary rider. The delayed request, disabled replacement, re-enabled replacement, and actual aborted GLB failure are separate checks. The report records resident native target and neighboring feature counts and target shader range values. A pyramid hidden ID can be checked even when that ordinary footprint has no pyramidal roof; actual relevant pyramid entries, if any, are reported separately. Disabling signature rendering in this harness refreshes the full vector-map suppression and pyramid masks as the host does for a supported rendering-mode change.

Bounded performance samples collect 90 actual game RAF frame intervals per model/site and one wide view in each device profile. The report includes the WebGL renderer string, viewport/device profile, render triangle/draw-call counters, native building memory counters, long tasks and request URLs. These measurements describe this browser/machine session; they are not a viewer FPS claim, a baseline comparison or a physical-phone measurement.
