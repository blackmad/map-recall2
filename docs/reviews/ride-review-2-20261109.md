## Verdict

The loop now hangs together: points, stamps and run totals agree across every card, the landmark question no longer gives itself away, Free Ride's collection pays off with a visible stamp on both devices, and the run card with Share run is the best end-of-ride screen the game has had. The one serious break is the run itself: a reload in the middle of a chained run throws the rider back to the setup form with a different destination, which undoes the "fare" idea on a phone where reloads are common. The rest is finish work — the Dutch game still slips into English at the moment of the answer and in place names, a few labels overflow on the phone and pause card, and the landmark question sometimes asks "which building" about a statue.
