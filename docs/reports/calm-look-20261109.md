## Measured results (2026-11-10, final)

Harness: `scripts/look/calm-measure.sh` (world-v1-ab, fixed camera zoom 17.5 pitch 60, DPR 1, 3D trees on). A = default, B = the flag. `base2` is A vs A (noise floor: pixel diff 0.00, identical numbers). Far/near are `scripts/look/busyness.mts` edge-energy ratios; "near" is the absolute near-region edge energy. Runs: `artifacts/calm/{base2,l4,l6,r2/l7,r3/l5live,r3/toonfrlive,r3/toonoldlive,r2/l3,r3/alllive}`. The last row of each lever is its westerkerk / bloemgracht-80 / nassaukade / leidsegracht-courtyard / ijburg-edge values; targets: far <= 0.5 x near (ratio <= 0.5), near unchanged, labels <= 6, <= 1 extra pass.

Three defects were found and fixed in this lane, each of which had made a lever measure as zero:

1. `labelCalm`: the shop reach used the eye-space depth of the label's anchor (`project(at).depth`). The chase camera sits ~350 m from its target (zoom 17.5, pitch 60), so every ground point is 230-430 m deep and every shop was dropped (0 labels at all spots). The rule is now the ground distance from the rider (camera target) <= 150 m. Pinned in `ownMap/labelCalm.test.ts` with a real camera frame (eye depth keeps 0, ground distance keeps 1-6).
2. `corridorFocus`: the fragment shader named a variable `half`, a reserved word in GLSL ES 1.00; the pass failed to compile and drew nothing (l7 pixel diff 0.00). Renamed `halfW`; the test now scans the shader for reserved words. After the fix the pass changes only the outside of the wedge (corner diff 47, centre-bottom 0.00).
3. `withWorkerFlags` (engine/workerPool.ts) forwarded only four flags to the building worker, so worker-built chunks never saw `look`, `toonFronts`, `roofFamily` or `treeCalm` (look/palette.ts and look/calmTones.ts read them at module load). `toonFronts` and the toon palette measured identical to `candy` before the fix. All four are forwarded now (test in `workerPool.test.ts`).

No lever reaches far <= 0.5 x near on its own or combined. The floor of the default far/near ratio is already 1.1-1.3 (the depth fade, lever 1, got it there); the 12 % dim of L7 is capped by design and moves the ratio about 4 %. A far/near <= 0.5 would need either a much stronger far fade (blurring or fogging the skyline, which the lighting/fog lanes own) or a different metric (the ratio is over Sobel energy per region, so the far region is intrinsically denser: more, smaller buildings per pixel).
