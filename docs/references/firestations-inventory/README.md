# Current Amsterdam firestation inventory

The current Brandweer Amsterdam-Amstelland operator index lists eleven land stations with Amsterdam in their names, plus Driemond and Weesp within the Amsterdam municipality: thirteen land stations. The inventory deliberately excludes regional stations in Aalsmeer, Amstelveen, Diemen, Duivendrecht and Uithoorn. The separately listed **Blusboot Jan van der Heyde IV** is a fireboat/boathouse entry, not admitted as an ordinary land-station building. Training and logistics sites do not enter this operational-station list automatically.

Official index: https://www.brandweer.nl/amsterdam-amstelland/kazernes/

`scripts/landmarks/firestations-inventory.json` records the official addresses, PDOK BAG address/VBO identifiers, explicit current municipal VBO-to-Pand parent links, and matching installed BAG tile features for every station. All thirteen Pand identities occur in the game's installed Amsterdam building tiles. No firestation-name entry existed in the manual catalogue at this research checkpoint. No genuine destination extract identity was found; new researched destinations still need coordinator integration. Coordinates are address/VBO points, not independently verified public entrances.

Raw operator HTML, PDOK JSON and municipal VBO/Pand JSON are preserved under the private sibling repository's `firestations-inventory/`, each with URL, actual retrieval time, HTTP status and SHA-256 provenance. These are original HTTP bodies. `research.py` reuses cached responses and makes up to three bounded attempts for uncached sources. It regenerates the public inventory and scans installed building tiles. The coordinator published the verified source pack in private commit `69186d12d` at `firestations-inventory/`.

The list and BAG parent relations are strong operator/municipal evidence. Per-building OSM relations, current facade/roof references, monument status, architect/history, public entrances and full model replacement scope remain separate build research. Absence from the modeled-name catalogue is a bounded audit, not a claim that every unnamed mesh was inspected. PDOK's Driemond address resolves to woonplaats Amsterdam, while the operator prints Driemond; both are retained. The operator's Weesp history inaccurately conflates 2021 safety-region transfer with municipal merger, so that sentence must not be copied into trivia.
