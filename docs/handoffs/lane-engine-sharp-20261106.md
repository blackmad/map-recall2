## What round two measured (#228, HISTORY "Engine round 2, R2-A")

- **Owner: trilinear mip blur.** `?cellDebug=rho` at DPR 2, tier high, ratio 2: the near quay walls sit at 4–16 texels per device pixel (near 63 % at 4–8, chase 30 % at 8–16); nothing is magnified; the tier's mean-colour `far` touches 2–3 %. A 256 px cell covers 16–64 device px, so windows come from mip 2–4 and a 2.5–6 texel painted frame blurs into the glass. 512 px cells cannot help (no gain measured in #224).
- **Analytic windows work but alias at DPR 2.** `look/windowTable.ts` (per atlas layer: up to 3 windows, rect in cell uv, shape, muntin code, inset, frame/glass tones; RGBA32F `DataTexture` 16 texels per row, `NearestFilter`, `texelFetch`) and `look/windowSdf.ts` (`CITY_WINDOW_SDF` in `cityLook.ts:373` and `litFacadeMaterial.ts:152`, program key `|wsdf1`, `windowSdfMix` uniform, `WINDOW_SDF_DESKTOP_DEFAULT = false`, `WINDOW_SDF_TOUCH_DEFAULT = false`, `:97-106`). AA is a box filter on `fwidth(uv × cell) × 1.25` (`:163`, `wsCover` `:136`); each window fades in by its opening size in px, `smoothstep(2.5, 5.0, sizePx)` (`:175-176`), and out with the tier's `far`. Measured: v1 with no fade lapVar at S2 +14–21 % desktop (1007 → 1218 at `da-costakade`), GPU within noise on desktop (5-run medians, `crisp-textures.spec` timer; the "iPhone" number is Mac-GPU emulation); but `aliasPx` (`swap-zfight.spec.ts` `ZFIGHT_SS`, `:201-234`) at the slab rose 34,356 → 66,777 at DPR 2 and 5,117 → 13,012 on the phone profile, because a box-filtered grid of 2–4 px openings beats against the pixel grid; the shipped [2.5, 5] px fade cut that to +41 % and the gain to +5 %, and a [5, 10] fade removed all gain. So it ships off on both tiers.
- **Texture path.** `threeBuildingsBrowser.ts lookTexturesOf` (`:319-333`): `DataArrayTexture`, `LinearMipmapLinearFilter`, `generateMipmaps = true`, anisotropy from `look/texturePolicy.ts` (16 desktop high); colour RGBA, mask `RedFormat`. The tier sample is `texture(cells, p)` with no bias and no `textureGrad` anywhere (`roofTier.ts:103`); mean colour via `textureLod(…, 12.0)`. **three@0.185.1 does not upload `texture.mipmaps[]` for a `DataArrayTexture`** (`WebGLTextures.js:1168-1208` uploads level 0 only; `getMipLevels :296-318` does count `mipmaps.length` when `generateMipmaps` is false, so placeholders make `texStorage3D` allocate N immutable levels). Custom levels therefore go in by hand: `renderer.initTexture(t)`, `renderer.properties.get(t).__webglTexture`, bind `TEXTURE_2D_ARRAY`, `gl.texSubImage3D(level, …)` per level; or a `CompressedArrayTexture` with RGBA uncompressed mips (`:1034-1108`, `:1092-1096`), which works for the colour atlas but not the R8 mask.
- **Pose.** `crispSpots.ts da-costakade` (z17.1 b-12 p70) is 150 m up; `da-costakade-chase` and `-near` are chase-height. The user's shot is in between (see the r2 strip `engine/2026-11-06-r2/r2a-s2-desktop-dpr2.jpg`: the lane's frame is more top-down than the user's).

2. **Band-limit the analytic windows** (`?windowSdf=1` semantics unchanged; new behaviour under the same define, `?windowSdfBand=0` restores round-two's shader for A/B). The rule, per feature, in screen px from the same `fw`: a **minimum screen width with energy-conserving coverage** like `railStripes.ts` (`half = min(cap, max(half, 0.625 × fu))`, coverage scaled so the integrated luminance is what the painted mip would give): frames never thinner than 1.0 px, with their contrast scaled down as the true width falls below it; glazing bars drop out first (fade 1.5 → 3 px bar width) and the glass tone then takes the bar's mean; openings below ~2.5 px per pitch blend to the painted (band-limited) texel instead of to nothing, i.e. the fade target is the mip sample, which it already is via `weight`. Keep the box filter but widen it to the true pixel footprint (`fwidth` at DPR 2 is per framebuffer pixel; check `× 1.25` is not under-filtering). Test in `windowSdf.test.ts` with a CPU twin of the coverage (as `stripeCoverage` does) that integrated coverage of a 0.5 px frame equals 0.5 × its tone. Gate: at `s3-slab` and `s3-slab-user` DPR 2, aliasPx ≤ the painted-cell baseline (34,356 at `s3-slab`), and lapVar at the S2 spots ≥ +10 % over painted on desktop.

Build levels 1..N on the CPU in `look/cellMips.ts` (typed, tested): a Kaiser or Lanczos-3 downsample per level from level 0 (not box-of-box), then a mild contrast-preserving step (unsharp on the window mask edges only, using the mask's G accent channel, so brick does not ring), gamma-correct. Upload by the manual `texSubImage3D` path (one helper, `look/arrayMipUpload.ts`, guarded so a missing `__webglTexture` falls back to GL mips). Keep the mean-colour level exact: the level the tier reads at LOD 12 must still be the per-layer mean (compute it from level 0). Mask stays GL-generated. Measure: texture MB unchanged (86.7), upload time at start (ms, once), lapVar / aliasPx at the four S2 spots and `s3-slab`, GPU unchanged.
