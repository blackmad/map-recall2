## Every integration round

1. Merge the lane with `/usr/bin/git merge --no-edit <branch>`.
2. Write the goldens, checking the CHANGED list first:
   - `fit-golden.ts --write`
   - `large-mesh-hashes.ts --write`
   - tile pilot `UPDATE_GOLDEN=1 node --import tsx --test src/canalRecall/tileBuildings/*.test.ts`
3. Rebuild covers: `NODE_OPTIONS=--max-old-space-size=12288 npx tsx scripts/build-covers.ts --tiles=<integrator>/artifacts/bag-tiles/bag-tiles/14 --out=artifacts/bag-tiles/covers.json`, then copy the output to `public/canal-drive/models/covers.json`.
4. Rebuild the data:
   - `census -- --write`
   - `build:content-stats`
   - `scripts/build-buurt-pages.ts`
   - `scripts/explorer/build-looks.ts`
   - the bundles that changed (`build:canal-building-types`, `build:canal-signature-landmarks`, …)
   - after building-types rounds, also `build:designs-images` and `build:designs-page`
5. Run the gate: `PW_PORT=4471 bash /tmp/canal-pw.sh npm run -s check:canal`.
6. Update the notes: HISTORY entry, TODO line, and the whats-new note.
7. Push: `git push origin HEAD:main HEAD:plan/thousand-buildings-20261023`.
8. Close the lane issue and comment on dev log #68. Then run `build:devlog` and commit `data/devlog.json`.
9. Commit and push the lane's crops in `map-recall2-source-data` (`pand-reference-walls/`). Leave other lanes' `datasets/` changes alone.
10. Read the feedback queue (`npm run -s feedback:queue`) and Sentry (`sentry-cli issues list --org whizziwig --project canal-recall`), and route new items to lanes.
