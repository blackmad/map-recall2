# Lane R4-J: the facade atlas's level 0 leaves the GPU from the air (~65 MB), with a facade-density trigger

Worktree `/Users/blackmad/Code/map-recall2-worktrees/engine-atlas-aerial-20261108`, branch `lane/engine-atlas-aerial-20261108` from `main` at 502a6c495 (after the R4-H merge), port 4669. Issue #254. Plan #222. Model: opus. Rules: `docs/handoffs/LANE-RULES.md`.

Engine round 4, after R4-G (#250) and R4-H (#252), HISTORY 2026-11-08. The aerial GPU budget (`aerialGlMaxMB`, 700 MB) is the one red aerial row: 690–760 MB on the legacy 4-byte figure, 624–684 decoded. The second-largest owner at the peak is the **facade atlas**: `look/cityLook.ts` (~line 889) builds a `DataArrayTexture` 256 × 256 × 208 layers, colour RGBA8 with a full mip chain (69 MB decoded) and a mask R8 (17 MB), both `texStorage3D` immutable, custom mip levels uploaded by `look/arrayMipUpload.ts` (R3-B #231, R3-E #240; `look/cellMips.ts` computes them). It is resident in full at every pose, including 3 km up where the GPU samples nothing finer than mip 2. Dropping level 0 from the air saves ~65 MB decoded (~52 + 13), about 109 MB on the legacy figure the budget row reads.

R4-G measured why this is not a one-liner: the user's S2 Da Costakade chase pose (z17.76, pitch 75.2) is `isAerialView` true (eye 74 m, reach 8.2 km), so a switch keyed on that predicate would soften the facades at a street pose the user looks at. The trigger has to be facade density: level 0 may go only when no drawn facade cell on screen needs it (the finest sampled mip over the facade draws is ≥ 1 for every chunk, with a margin), and it must come back before the camera lands (a sliced restore, so no 50+ ms frame on the way down). Immutable storage means "dropping level 0" is a second texture object (128 × 128 × 208 with levels 1..n as its 0..n−1), a material/uniform switch and a mip-bias / lod-offset adjustment, not a `TEXTURE_BASE_LEVEL` change (which frees nothing).

## What is wanted

Post it on #254 before building the switch.
2. **The switch.** `?atlasAerial=1` (default off until measured; the integrator flips): when the finest sampled facade mip has been ≥ 1 + margin for N frames, swap the facade material's array samplers to a half-size pair (built once from the CPU-side level-1..n data `cellMips.ts` already holds; upload sliced over frames so no frame pays more than ~4 ms), then dispose the full pair's GL storage; when the finest wanted mip drops under 1 + margin (the camera coming down, a landing from the start flight, a free-ride landing), rebuild the full pair sliced over frames (level 0 by layer bands, ~4 ms a frame) and switch back before the first frame that would sample level 0: the rider must never see a soft facade. Hysteresis on both edges. New facade cells arriving while half-size (atlas layer writes, `bayTextures.ts` / slot cells) must update both the resident pair and the CPU copy so the restore is current.
