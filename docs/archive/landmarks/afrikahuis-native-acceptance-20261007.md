# Afrikahuis native acceptance checkpoint

Afrikahuis now has an original texture-free native reconstruction of its linked octagons, raised corner church, open forecourt, limestone/concrete walls and projecting glass stairs. A taller presbytery retains its distinct ribbons and repaired recessed V entrance, central core, flared beams and fan approach. Root and a fresh independent reviewer inspected source comparisons, gallery default/four rotations and actual city views. Current source-derived scope passed local acceptance; hosted verification is pending.

The production mesh is 28,070 triangles and 400,140 bytes, SHA256 09ff3adba973233b03ab2f7a1dddd4b6a21b85e9fd603658c66273c1042a0fc7. It uses native metres at anchor [4.897546,52.352932], scale 1. Exact replacements are current OSM w44451421 and BAG 0363100012108180. Four actual resident school/residential neighbors remain drawable. Disabled and forced missing-GLB cases restore ordinary fallback, leaving the chosen destination unchanged. No replaced pyramid is resident here, so no drawn target-pyramid claim is made.

All three POI surfaces were verified together: explicitly chosen genuine extract_landmarks_1448512409, geographic pin and label at the western boundary anchor, and physical mesh clicking of a meaningful architectural card. The primary card source is the archived accessible Amsterdam op de Kaart page; municipal register remains an additional reference with its direct HTTP access gap recorded. Normal D toggling enables the actual named map label; HUD-only-hidden diagnostic screenshots are separately identified. The De Avonturijn label in oblique images belongs to the neighboring school.

Actual running gameplay mouse/touch-emulated gestures move the camera away from a zero-speed stationary rider, preserving ordinary textured windows and ground-floor entrances. Root inspected both gesture PNGs. Installed Chrome 154 / ANGLE Metal Apple M4 Pro / 1500×1000 / DPR1 controlled five alternating 90-frame model/fallback samples: all medians 16.7 ms, p95 16.7–16.8 ms, with camera/player/28 chunks/41 other signatures and ordinary geometry/texture memory invariant. This bounds the model cost in one desktop scene; it does not establish physical mobile, full-game performance or precise GPU-time savings.

Preserved failures include the initial wrong presbytery ground assembly and roof gap, blocked distant city cameras, software/global-toggle ~208/200 ms timings, and the paused-state gesture that did not move the camera. Existing MapLibre icon opacity/layout errors after D toggling reproduce on shipping baseline without this model; the toggle console is not clean. These warnings are a separate unresolved runtime issue.
