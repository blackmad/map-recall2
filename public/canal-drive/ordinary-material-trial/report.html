Poly Haven material trial

This is a comparison demo, not a production material change. Interactive comparison · Source and image comparisons.

Generic brick and concrete luminance is gently applied only to wall pixels of the existing facade atlas. Original windows, doors, trim, shutters and signage remain pixel-identical, and geometry/material counts stay unchanged. Building reference photos are not used as model textures.

The fair material cost is +24,676/+23,468 bytes versus optimized original appearance. Lower modern file size versus published comes from lossless PNG encoding, not from adding texture.

Brick courses are subtly visible close up and mostly disappear at a distance. Concrete is nearly invisible; it is not a worthwhile production choice on this evidence. Each GLB embeds its combined atlas; this demo does not share one GPU texture across buildings.

CPU images approximate shading and mip minification. Native WebGL comparison provides real browser shading but is isolated from the game. Game motion, loading/decode, texture upload and frame timing acceptance remain pending. Neither finish is accepted for the live game.
