# Postcard fonts

All three are licensed under the SIL Open Font License 1.1 and come from the google/fonts repository.

- `Anton-Regular.ttf`: the large-letter name. It is a condensed extra-bold face, standing in for the Futura Condensed Extra Bold of the classic recipe.
- `Pacifico-Regular.ttf`: the "Greetings from" script. It is self-hosted so the card never falls back to a serif.
- `ArchivoBlack-Regular.ttf`: the earlier name face, which the Canal Drive pages still load from Google Fonts by name.
